## Короткая формулировка для вставки в диплом

Интеллект-карта использована как инструмент систематизации проверок дипломного проекта «Проектирование и разработка WEB-приложения на Java для интеллектуального подбора обуви с рекомендательной моделью». Карта структурирует тестирование по 4 направлениям (UI, API, БД, безопасность), обеспечивает прослеживаемость требований ТЗ и снижает риск пропуска критичных сценариев перед защитой.
